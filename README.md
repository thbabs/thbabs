## Featured projects

### [Malicious URL detection (BERT vs LSTM)](https://github.com/thbabs/Detecting-Malicious-URLs-using-Google-s-BERT-and-LSTM-models)

- **Problem:** Classify URLs as malicious or benign.
- **Approach:** Compared an LSTM with pre-trained BERT on 522,214 imbalanced rows (70/30 train-test split), using accuracy, loss, and a confusion matrix.
- **Result:** LSTM validation accuracy was 91.36% (loss 0.25). BERT reached 75.9% after classifier initialisation and hardware problems.
- Write-up: [Towards Data Science](https://towardsdatascience.com/detecting-malicious-urls-using-lstm-and-googles-bert-models/)

### [UK census: development and investment](https://github.com/thbabs/UK-CENSUS---Predicting-development-and-Investment)

- **Problem:** Use a 2022 UK census extract to show what should guide a town's development and investment.
- **Approach:** Cleaned 10,593 records and analysed household occupancy, commuting, migration, births, and deaths.
- **Result:** Net migration of 12.7 per thousand and probable population growth of 0.25%. Households held up to 21 people.

### [GDP dashboard](https://github.com/thbabs/gdp-dashboard)

- **Problem:** Compare national GDP across countries and years from one screen.
- **Approach:** Streamlit app on World Bank Open Data (1960–2022), with a year slider, a country filter, and a line chart.
- **Result:** Metric cards for the selected countries, showing GDP in billions and the growth multiple over the chosen years.

### [SportBot](https://github.com/thbabs/SportBot)

- **Problem:** Run a conversational LLM app locally, without a separate backend.
- **Approach:** Streamlit chat UI on OpenAI GPT-3.5, with the thread kept in session state and replies streamed. The user supplies an API key.
- **Result:** A working chatbot template that keeps the conversation and streams each reply.
